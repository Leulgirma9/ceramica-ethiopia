# Ceramica Ethiopia

> Premium Ceramic & Porcelain Tile Catalog inspired by the editorial design language of Atlas Concorde.

## 🌟 Overview
Ceramica Ethiopia is a web platform and luxury digital showroom designed for high-end ceramics, porcelain tiles, sanitary ware, and architectural fixtures.

### Key Features
- **Editorial Aesthetic**: Inspired by Atlas Concorde, with minimal design, refined typography (`Cormorant Garamond` + `Montserrat`), and neutral architectural palettes.
- **Dynamic Catalog**: Full product browsing with category filtering, surface finish filtering, and application filtering.
- **Product Details**: Technical specifications, dimensions, finish options, and high-res imagery.
- **Admin Dashboard**: Secure management of products, categories, inventory, and site settings.
- **Lightweight & Fast**: Built with Vanilla JS, clean CSS, Node.js/Express, and SQLite.

## 🚀 Quick Start

### 1. Installation
```bash
git clone https://github.com/Leulgirma9/ceramica-ethiopia.git
cd ceramica-ethiopia
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```

### 3. Start the Server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

Navigate to [http://localhost:3000/#admin](http://localhost:3000/#admin) or click the Admin link in the footer:
